# Restore the original portfolio media here

Copy your original media into these folders with the **same exact filenames**. The website refers to the paths below.

- `gallery/videos/`: 10 original MP4 files
- `gallery/renders/`: 10 original PNG files
- `covers/`: optional project cover images

The media is intentionally not included here because you removed the large files from the uploaded ZIP. Cards show placeholders until you add the files. No renaming is needed.

Note that filenames are case-sensitive on GitHub Pages, including `Video-03-Fun-Animation.mp4`.
